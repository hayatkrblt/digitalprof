# ActiveSlide

Upload lecture slides (PDF or image) and get a varied version that fights the "illusion of competence": explanations are paraphrased, blocks are rearranged, and fill-in-the-blank questions are added. Core terminology, formulas and diagrams are never altered. The result is rendered back to a downloadable PDF.

## Run

System dependency for PDF export: WeasyPrint needs Pango (`sudo apt install libpango-1.0-0 libpangoft2-1.0-0`).

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then add OPENAI_API_KEY
streamlit run app.py
python scripts/run_examples.py   # regenerates examples/interactions.md
```

Limits: 10 pages and 25 MB per upload.

## Models and libraries

- Model: `gpt-4o` by default (vision + structured outputs), configurable with `OPENAI_MODEL`. The committed examples were generated with `anthropic/claude-sonnet-5.5` through OpenRouter (`OPENAI_BASE_URL=https://openrouter.ai/api/v1`).
- Libraries: `openai`, `pydantic` (strict schemas), `streamlit` (UI), `pymupdf` (PDF to image), `Pillow` (cropping), `Jinja2` + `WeasyPrint` (HTML to PDF), `python-dotenv`.

## 5-stage architecture

| Stage | File | Responsibility |
|---|---|---|
| Input | `src/input.py` | Validate file type/size/page count, normalize the query, rasterize PDF pages, base64 encode |
| Knowledge | `src/knowledge.py` | Load `data/preservation_rules.json` and build the system prompt |
| Tools | `src/tools.py` | `extract_and_categorize_slide` (visuals / terminology / tweakable text) and `generate_active_recall_masks` |
| Decisions | `src/agent.py` | Routing (`tweak_layout`, `light_paraphrase`, `preserve_only`, `refuse`), guardrails, terminology check |
| Output | `src/output.py` | JSON response with debug trace; Jinja2 + WeasyPrint PDF |

`app.py` is the Streamlit frontend over these stages.

## Custom logic

- **Visuals are cropped, never redrawn.** The model only reports bounding boxes; the original pixels are cut out with Pillow and placed in the new layout.
- **Terminology guard.** After paraphrasing, code checks that every core term from the original text still appears verbatim. One retry, then the original text is kept and a warning is added.
- **Boundary enforcement.** Prompt-injection phrases are refused in code before any model call; non-slide images and out-of-scope requests (homework, essays, requests to alter protected visuals) are refused by the router with a polite message.
- **Fixed layouts.** The model picks one of `text_left`, `text_right`, `stacked`; one shared template keeps the art style consistent.
- **Masks.** Questions must contain exactly one `[MASK]` and unique options; invalid ones are dropped. The PDF gets a "Check yourself" page and an answer key.
